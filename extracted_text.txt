MIDTERM GROUP PROJECT 2026
Management of Organizational Data | Master’s Programme | 10 Groups / 37 Students
Project theme: Java Source Code Vulnerability Detection
Each group 3 or 4 Master Students 
Tools: Python
Project objective: 
The project demonstrates how effective organizational data management supports the development of reliable AI-based systems. Vulnerability detection serves as a practical application in which Master students must manage the complete data lifecycle, ensure data quality and security, design data processing pipelines, and transform analytical results into informed decisions.
The comparison of primary and alternative AI methods also develops students' ability to evaluate technological solutions based on organizational requirements, available resources, data characteristics, computational efficiency, and implementation risks.
Therefore, the main learning objective is not only to achieve high classification accuracy but also to demonstrate how data governance, data quality, integration, security, and analytics contribute to effective organizational decision-making.
Students must demonstrate how organizational data management principles influence the development, reliability, security, and effectiveness of intelligent software systems.
Each group must address the following aspects:
Lecture 1 — Organizational Data Management: Describe the dataset lifecycle, from collection and storage to processing, analysis, and decision-making.
Lecture 2 — Data Governance: Define data ownership, access responsibilities, data usage policies, and ethical considerations.
Lecture 3 — Data Modeling: Develop a conceptual data model or ER diagram describing the dataset, Java functions, vulnerability labels, and experimental results.
Lecture 4 — Data Warehousing and ETL: Demonstrate data extraction, transformation, loading, and integration into the transformer or machine learning workflow.
Lecture 5 — Data Quality: Perform data cleaning, duplicate detection, preprocessing, class distribution analysis, and data quality assessment.
Lecture 6 — Data Security: Explain secure data storage, access control, confidentiality, and risks associated with organizational data.
Lecture 7 — Data Analytics and Visualization: Evaluate model performance using Accuracy, Precision, Recall, F1-score, ROC-AUC, and Confusion Matrix. Visualize the results and provide data-driven recommendations.
